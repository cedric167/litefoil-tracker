## Sécurité des données : ce qui change

Les sessions de l'Atelier VESC utilisent maintenant le **GPS du téléphone** (seulement quand on lance
une session, avec l'autorisation de position demandée par Chrome). La trace reste sur le téléphone ;
la carte est chargée depuis Esri, qui voit donc les zones de carte affichées, comme pour toute carte en
ligne.

Dans Play Console → **Contenu de l'application → Sécurité des données → Modifier**, la réponse
prudente est :

- *Position → Position précise* : **collectée** (cocher), **non partagée**, **traitement éphémère : non**
  (la trace est gardée sur le téléphone), **facultative** (seulement si on lance une session),
  finalité **Fonctionnalités de l'application**.

Tout le reste du formulaire est inchangé (e-mail et mot de passe SportsTrackLive, pas de publicité,
pas d'analyse d'audience, données chiffrées en transit, suppression possible).
