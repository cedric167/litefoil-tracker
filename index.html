Le tracker se connecte lui-même à SportsTrackLive avec ces identifiants et y crée la session de chaque sortie, comme l'application du téléphone. Si le site les refuse, la tuile « Session STL » l'indique. Le mot de passe est conservé dans la mémoire du tracker (lisible par USB).
Avancé : vérifier les identifiants depuis le téléphone (clé d'application STL)
Facultatif. Avec cette clé, le téléphone vérifie l'e-mail et le mot de passe auprès du site avant de les enregistrer. Elle reste dans ce navigateur.
